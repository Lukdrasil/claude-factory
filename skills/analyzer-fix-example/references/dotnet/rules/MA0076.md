# MA0076: Do not use implicit culture-sensitive ToString in interpolated strings

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: info · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0076.md

## Wrong

```csharp
namespace Kit.Billing.Application.Features.GenerateInvoice;

internal sealed class InvoiceLineFormatter
{
    public string FormatTotal(decimal total)
        => $"Total: {total}"; // MA0076: implicit culture-sensitive ToString in interpolation
}
```

## Right

```csharp
namespace Kit.Billing.Application.Features.GenerateInvoice;

using System.Globalization;

internal sealed class InvoiceLineFormatter
{
    public string FormatTotal(decimal total)
        => string.Create(CultureInfo.InvariantCulture, $"Total: {total}");
}
```

**Principle**: Each hole in an interpolated string calls the culture-sensitive `ToString()` of its value under the hood, so `string.Create(CultureInfo.InvariantCulture, $"...")` pins the whole interpolation to one culture instead of the thread's ambient one.

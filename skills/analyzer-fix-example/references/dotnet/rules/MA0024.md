# MA0024: Use an explicit StringComparer when possible

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0024.md

## Wrong

```csharp
namespace Kit.Catalog.Application.Features.MatchSku;

internal sealed class SkuMatcher
{
    public bool AreEqual(string left, string right) =>
        EqualityComparer<string>.Default.Equals(left, right); // MA0024: implicit comparer
}
```

## Right

```csharp
namespace Kit.Catalog.Application.Features.MatchSku;

internal sealed class SkuMatcher
{
    public bool AreEqual(string left, string right) =>
        StringComparer.Ordinal.Equals(left, right);
}
```

**Principle**: EqualityComparer<string>.Default resolves to the runtime's default string comparer and hides the comparison rule from the reader; StringComparer.Ordinal states explicitly that SKU matching is exact and culture-independent.

# CA1062: Validate arguments of public methods

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA1062.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1062

## Wrong

```csharp
using System.Text;

namespace Infrastructure.Billing;

public sealed class InvoicePdfExporter
{
    public byte[] Export(InvoiceDto invoice) // CA1062: 'invoice' not null-checked
    {
        return System.Text.Encoding.UTF8.GetBytes(invoice.Number);
    }
}

public sealed record InvoiceDto(string Number, decimal Total);
```

## Right

```csharp
using System.Text;

namespace Infrastructure.Billing;

public sealed class InvoicePdfExporter
{
    public byte[] Export(InvoiceDto invoice)
    {
        ArgumentNullException.ThrowIfNull(invoice);
        return System.Text.Encoding.UTF8.GetBytes(invoice.Number);
    }
}

public sealed record InvoiceDto(string Number, decimal Total);
```

**Principle**: A publicly reachable method fails fast with a clear `ArgumentNullException` instead of an obscure `NullReferenceException` two frames deeper.

**Layer note**: Applies to externally visible members; Infrastructure adapters implementing a Port, or Contracts-facing entry points; internal-only Application handlers reached solely through the mediator can instead rely on a validation pipeline.

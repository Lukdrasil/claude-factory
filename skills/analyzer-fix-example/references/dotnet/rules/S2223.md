# S2223: Non-constant static fields should not be visible

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2223/

## Wrong

```csharp
namespace Kit.Catalog.Domain;

public sealed class PricingDefaults
{
    public static decimal TaxRate = 0.2m; // Noncompliant: mutable and publicly visible
}
```

## Right

```csharp
namespace Kit.Catalog.Domain;

public sealed class PricingDefaults
{
    public const decimal TaxRate = 0.2m;
}
```

**Principle**: Any caller anywhere in the process can write `PricingDefaults.TaxRate = 0` and change pricing for every other consumer at once; a `const` (or a `static readonly` set once at startup) makes that value impossible to mutate from outside.

**Layer note**: In the Domain layer this is stricter than "make it const"; mutable shared state on a domain type breaks the aggregate's own invariants across every instance; prefer passing the rate in as a parameter or reading it from a Domain-owned policy object instead of a static field at all.

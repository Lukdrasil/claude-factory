# MA0129: Await task in using statement

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0129.md

## Wrong

```csharp
namespace Kit.Inventory.Infrastructure;

internal sealed class WarehouseLockManager
{
    public async Task ReserveAsync(string sku, CancellationToken cancellationToken)
    {
        Task<IDisposable> lockTask = AcquireLockAsync(sku, cancellationToken);
        using (lockTask) // MA0129: disposing the Task, not the lock it produces
        {
            await Task.Delay(10, cancellationToken);
        }
    }

    private Task<IDisposable> AcquireLockAsync(string sku, CancellationToken cancellationToken)
        => Task.FromResult<IDisposable>(new NoopLock());

    private sealed class NoopLock : IDisposable { public void Dispose() { } }
}
```

## Right

```csharp
namespace Kit.Inventory.Infrastructure;

internal sealed class WarehouseLockManager
{
    public async Task ReserveAsync(string sku, CancellationToken cancellationToken)
    {
        using (await AcquireLockAsync(sku, cancellationToken))
        {
            await Task.Delay(10, cancellationToken);
        }
    }

    private Task<IDisposable> AcquireLockAsync(string sku, CancellationToken cancellationToken)
        => Task.FromResult<IDisposable>(new NoopLock());

    private sealed class NoopLock : IDisposable { public void Dispose() { } }
}
```

**Principle**: `using` on a `Task<IDisposable>` disposes the task wrapper, not the lock handle it will eventually produce, and never actually waits for acquisition; awaiting the task first gets the real resource into the `using` block.

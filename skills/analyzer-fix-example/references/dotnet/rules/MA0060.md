# MA0060: The return value of the method should be used

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0060.md

## Wrong

```csharp
namespace Kit.Documents.Infrastructure;

internal sealed class DocumentHeaderReader
{
    public async Task<byte[]> ReadHeaderAsync(string path, CancellationToken cancellationToken)
    {
        await using var stream = File.OpenRead(path);
        var buffer = new byte[16];
        stream.Read(buffer, 0, buffer.Length); // MA0060: return value ignored
        return buffer;
    }
}
```

## Right

```csharp
namespace Kit.Documents.Infrastructure;

internal sealed class DocumentHeaderReader
{
    public async Task<byte[]> ReadHeaderAsync(string path, CancellationToken cancellationToken)
    {
        await using var stream = File.OpenRead(path);
        var buffer = new byte[16];
        var bytesRead = await stream.ReadAsync(buffer.AsMemory(0, buffer.Length), cancellationToken);
        return buffer.AsSpan(0, bytesRead).ToArray();
    }
}
```

**Principle**: `Stream.Read` can return fewer bytes than requested, so discarding the count silently treats a partial read as a complete one; capturing it is the only way to know how much of the buffer is actually valid.

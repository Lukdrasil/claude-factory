# MA0053: Make class sealed

**Analyzer**: Meziantou.Analyzer · **Kit config**: warning in Domain; none in tests · **Docs**: https://raw.githubusercontent.com/meziantou/Meziantou.Analyzer/main/docs/Rules/MA0053.md

## Wrong

```csharp
namespace Kit.Orders.Domain;

public class Money // no inheritors, not sealed
{
    public decimal Amount { get; }
    public string Currency { get; }

    public Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }
}
```

## Right

```csharp
namespace Kit.Orders.Domain;

public sealed class Money
{
    public decimal Amount { get; }
    public string Currency { get; }

    public Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }
}
```

**Principle**: A domain type with no inheritors left open invites subclassing that would let a caller bypass its invariants through overriding; sealing it makes the design intent explicit and lets the runtime skip virtual dispatch.

**Layer note**: Enforced in Domain, where types are meant to be closed value/entity shapes; test-only classes (fakes, builders meant to be extended per test) are exempt.

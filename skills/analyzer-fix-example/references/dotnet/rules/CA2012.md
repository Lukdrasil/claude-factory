# CA2012: Use ValueTasks correctly

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: error · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca2012

## Wrong

```csharp
namespace Orders.Infrastructure.Caching;

internal sealed class OrderCache
{
    internal async ValueTask<int> GetCachedCountAsync(CancellationToken cancellationToken)
    {
        await Task.Delay(10, cancellationToken);
        return 42;
    }

    internal async Task<int> SumTwiceAsync(CancellationToken cancellationToken)
    {
        ValueTask<int> countTask = GetCachedCountAsync(cancellationToken);
        var first = await countTask;
        var second = await countTask; // analyzer fires here
        return first + second;
    }
}
```

## Right

```csharp
namespace Orders.Infrastructure.Caching;

internal sealed class OrderCache
{
    internal async ValueTask<int> GetCachedCountAsync(CancellationToken cancellationToken)
    {
        await Task.Delay(10, cancellationToken);
        return 42;
    }

    internal async Task<int> SumTwiceAsync(CancellationToken cancellationToken)
    {
        var first = await GetCachedCountAsync(cancellationToken);
        var second = await GetCachedCountAsync(cancellationToken);
        return first + second;
    }
}
```

**Principle**: A `ValueTask`'s backing state (a pooled builder or a reused `IValueTaskSource`) can be recycled the instant it is first consumed, so awaiting the same `ValueTask` a second time reads torn or reused state instead of the original result.

# IDE0051: Remove unused private member

**Analyzer**: IDE built-in · **Kit config**: warning (unused private member) · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/style-rules/ide0051

## Wrong

```csharp
namespace Acme.Features.Orders;

internal sealed class OrderPriceCalculator
{
    private const decimal LegacyDiscountRate = 0.05m; // marker: never read

    public decimal Calculate(decimal price, int quantity) => price * quantity;
}
```

## Right

```csharp
namespace Acme.Features.Orders;

internal sealed class OrderPriceCalculator
{
    public decimal Calculate(decimal price, int quantity) => price * quantity;
}
```

**Principle**: an unused private member is dead code that only a full-class read can rule out as safe to ignore, so deleting it keeps the class's real behavior visible at a glance.

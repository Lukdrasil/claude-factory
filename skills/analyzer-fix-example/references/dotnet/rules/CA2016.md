# CA2016: Forward the CancellationToken parameter to methods that take one

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: error · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca2016

## Wrong

```csharp
namespace Orders.Application.Handlers;

internal sealed class ArchiveOrderHandler(IOrderRepository repository)
{
    internal async Task HandleAsync(Guid orderId, CancellationToken cancellationToken)
    {
        var order = await repository.GetOrderAsync(orderId); // analyzer fires here
        await repository.ArchiveAsync(order, cancellationToken);
    }
}

internal interface IOrderRepository
{
    Task<Order> GetOrderAsync(Guid orderId, CancellationToken cancellationToken = default);
    Task ArchiveAsync(Order order, CancellationToken cancellationToken);
}

internal sealed record Order(Guid Id);
```

## Right

```csharp
namespace Orders.Application.Handlers;

internal sealed class ArchiveOrderHandler(IOrderRepository repository)
{
    internal async Task HandleAsync(Guid orderId, CancellationToken cancellationToken)
    {
        var order = await repository.GetOrderAsync(orderId, cancellationToken);
        await repository.ArchiveAsync(order, cancellationToken);
    }
}

internal interface IOrderRepository
{
    Task<Order> GetOrderAsync(Guid orderId, CancellationToken cancellationToken = default);
    Task ArchiveAsync(Order order, CancellationToken cancellationToken);
}

internal sealed record Order(Guid Id);
```

**Principle**: Dropping the token at one call site breaks the cancellation chain at that point; everything downstream of it can no longer be cancelled, even though the caller asked for cooperative cancellation.

# S2372: Exceptions should not be thrown from property getters

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2372/

## Wrong

```csharp
namespace Kit.Orders.Domain;

internal sealed record OrderLine(decimal Amount);

internal sealed class OrderEmptyException : Exception;

public sealed class Order
{
    private readonly List<OrderLine> _lines = [];

    public decimal Total
    {
        get
        {
            if (_lines.Count == 0)
            {
                throw new OrderEmptyException(); // Noncompliant
            }
            return _lines.Sum(l => l.Amount);
        }
    }
}
```

## Right

```csharp
namespace Kit.Orders.Domain;

internal sealed record OrderLine(decimal Amount);

internal sealed class OrderEmptyException : Exception;

public sealed class Order
{
    private readonly List<OrderLine> _lines = [];

    public decimal GetTotal()
    {
        if (_lines.Count == 0)
        {
            throw new OrderEmptyException();
        }
        return _lines.Sum(l => l.Amount);
    }
}
```

**Principle**: Callers read a property as a cheap, always-safe field access and don't wrap it in a `try`/`catch`; a throwing computation belongs on a method name that signals it can fail, so `GetTotal()` warns where `Total` would not.

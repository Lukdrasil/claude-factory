# S5034: "ValueTask" should be consumed correctly

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-5034/

## Wrong

```csharp
namespace Kit.Catalog.Infrastructure.Caching;

internal sealed record ProductId(Guid Value);

internal sealed class ProductPriceCache
{
    public async Task<decimal> GetTotalAsync(ProductId id, CancellationToken cancellationToken)
    {
        ValueTask<decimal> priceTask = GetPriceAsync(id, cancellationToken);
        decimal first = await priceTask;
        decimal second = await priceTask; // Noncompliant: same ValueTask consumed twice
        return first + second;
    }

    private ValueTask<decimal> GetPriceAsync(ProductId id, CancellationToken cancellationToken) =>
        ValueTask.FromResult(9.99m);
}
```

## Right

```csharp
namespace Kit.Catalog.Infrastructure.Caching;

internal sealed record ProductId(Guid Value);

internal sealed class ProductPriceCache
{
    public async Task<decimal> GetTotalAsync(ProductId id, CancellationToken cancellationToken)
    {
        decimal price = await GetPriceAsync(id, cancellationToken);
        return price + price;
    }

    private ValueTask<decimal> GetPriceAsync(ProductId id, CancellationToken cancellationToken) =>
        ValueTask.FromResult(9.99m);
}
```

**Principle**: A `ValueTask`'s backing operation may be pooled or single-use, so awaiting the same instance a second time (or from two places concurrently) is undefined behavior; await it exactly once, and if the result must be reused, capture it in a variable instead of re-awaiting the `ValueTask`.

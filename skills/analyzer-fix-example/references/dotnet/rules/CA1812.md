# CA1812: Avoid uninstantiated internal classes

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: suggestion · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1812

## Wrong

```csharp
namespace Kit.Modules.Orders.Application.Features.PlaceOrder;

internal sealed record PlaceOrderCommand(Guid CustomerId, decimal Amount);

internal interface IOrderRepository
{
    Task AddAsync(PlaceOrderCommand command, CancellationToken ct);
}

internal sealed class PlaceOrderHandler(IOrderRepository repository) // resolved only via DI - analyzer finds no "new"
{
    public Task HandleAsync(PlaceOrderCommand command, CancellationToken ct) =>
        repository.AddAsync(command, ct);
}
```

## Right

```csharp
using System.Diagnostics.CodeAnalysis;
using Microsoft.Extensions.DependencyInjection;

namespace Kit.Modules.Orders.Application.Features.PlaceOrder;

internal sealed record PlaceOrderCommand(Guid CustomerId, decimal Amount);

internal interface IOrderRepository
{
    Task AddAsync(PlaceOrderCommand command, CancellationToken ct);
}

[SuppressMessage("Performance", "CA1812:Avoid uninstantiated internal classes",
    Justification = "Instantiated by the DI container when PlaceOrderCommand is dispatched.")]
internal sealed class PlaceOrderHandler(IOrderRepository repository)
{
    public Task HandleAsync(PlaceOrderCommand command, CancellationToken ct) =>
        repository.AddAsync(command, ct);
}

internal static class PlaceOrderModule
{
    public static IServiceCollection AddPlaceOrder(this IServiceCollection services) =>
        services.AddScoped<PlaceOrderHandler>();
}
```

**Principle**: A handler resolved only through the DI container has no source-visible constructor call for the analyzer to find, so a scoped, justified `[SuppressMessage]` documents that the instantiation happens at runtime instead of silencing the rule project-wide.

# S3168: "async" methods should not return "void"

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3168/

## Wrong

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class OrderPlacedNotifier
{
    public async void NotifyAsync(Guid orderId) // Noncompliant: async void; exceptions escape unobserved
    {
        await Task.Delay(TimeSpan.FromMilliseconds(1));
        throw new InvalidOperationException("Notification failed");
    }
}
```

## Right

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class OrderPlacedNotifier
{
    public async Task NotifyAsync(Guid orderId, CancellationToken cancellationToken)
    {
        await Task.Delay(TimeSpan.FromMilliseconds(1), cancellationToken);
        throw new InvalidOperationException("Notification failed");
    }
}
```

**Principle**: `Task` carries the exception on its result so callers can await it, observe failures, and unit-test it; `void` silently discards all three, which is the same defect VSTHRD100 flags for async void methods, so fixing this also clears that diagnostic.

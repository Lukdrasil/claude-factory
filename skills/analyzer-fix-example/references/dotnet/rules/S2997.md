# S2997: "IDisposables" created in a "using" statement should not be returned

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2997/

## Wrong

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportFileFactory
{
    public FileStream OpenForWrite(string path)
    {
        using var stream = File.Create(path); // Noncompliant: disposed before the caller can use it
        return stream;
    }
}
```

## Right

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportFileFactory
{
    public FileStream OpenForWrite(string path)
    {
        var stream = File.Create(path);
        return stream;
    }
}
```

**Principle**: returning a disposable transfers ownership to the caller, so the factory must not dispose it first; the caller becomes responsible for eventual disposal, typically via `await using` at the call site.

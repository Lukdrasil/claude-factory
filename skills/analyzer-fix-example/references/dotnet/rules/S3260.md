# S3260: Non-derived "private" classes and records should be "sealed"

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3260/

## Wrong

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class PlaceOrderHandler
{
    public Task<Guid> HandleAsync(PlaceOrderCommand command, CancellationToken cancellationToken)
    {
        var summary = new LineSummary(command.Quantity, command.UnitPrice);
        return Task.FromResult(Guid.NewGuid());
    }

    private class LineSummary // Noncompliant: private, never derived from, but not sealed
    {
        public LineSummary(int quantity, decimal unitPrice) => Total = quantity * unitPrice;

        public decimal Total { get; }
    }
}

internal sealed record PlaceOrderCommand(int Quantity, decimal UnitPrice);
```

## Right

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class PlaceOrderHandler
{
    public Task<Guid> HandleAsync(PlaceOrderCommand command, CancellationToken cancellationToken)
    {
        var summary = new LineSummary(command.Quantity, command.UnitPrice);
        return Task.FromResult(Guid.NewGuid());
    }

    private sealed class LineSummary
    {
        public LineSummary(int quantity, decimal unitPrice) => Total = quantity * unitPrice;

        public decimal Total { get; }
    }
}

internal sealed record PlaceOrderCommand(int Quantity, decimal UnitPrice);
```

**Principle**: a type nobody can see outside its own scope and nobody derives from is already effectively closed for extension; marking it `sealed` lets the JIT devirtualize its member calls and tells the next reader no subclass is coming.

# S1481: Unused local variables should be removed

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-1481/

## Wrong

```csharp
namespace Kit.Scheduling.Features.EstimateDuration;

internal sealed class DurationEstimator
{
    public int EstimateMinutes(int hours)
    {
        var seconds = hours * 3600; // unused local variable
        return hours * 60;
    }
}
```

## Right

```csharp
namespace Kit.Scheduling.Features.EstimateDuration;

internal sealed class DurationEstimator
{
    public int EstimateMinutes(int hours)
    {
        return hours * 60;
    }
}
```

**Principle**: A local that is assigned and never read is either leftover from an earlier version of the method or a sign the intended computation was never wired up; either way it adds a line a reader must decode for no result.

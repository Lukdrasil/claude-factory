# MA0055: Do not use finalizer

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0055.md

## Wrong

```csharp
namespace Kit.Documents.Infrastructure.Storage;

internal sealed class UnmanagedBuffer(nint handle) : IDisposable
{
    ~UnmanagedBuffer() // MA0055: finalizer
    {
        NativeMethods.Free(handle);
    }

    public void Dispose() => GC.SuppressFinalize(this);
}

internal static class NativeMethods
{
    public static void Free(nint handle) { }
}
```

## Right

```csharp
using System.Runtime.InteropServices;

namespace Kit.Documents.Infrastructure.Storage;

internal sealed class UnmanagedBufferHandle : SafeHandle
{
    public UnmanagedBufferHandle(nint handle) : base(invalidHandleValue: 0, ownsHandle: true) =>
        SetHandle(handle);

    public override bool IsInvalid => handle == 0;

    protected override bool ReleaseHandle()
    {
        NativeMethods.Free(handle);
        return true;
    }
}

internal static class NativeMethods
{
    public static void Free(nint handle) { }
}
```

**Principle**: A hand-written finalizer runs on a dedicated finalizer thread at an unpredictable time and adds every instance to the finalization queue, a real GC cost; deriving from SafeHandle gives the runtime a critical finalizer that reliably releases the native handle without writing one yourself.

**Layer note**: This pattern belongs to Infrastructure adapters that wrap native or unmanaged resources; Domain and Application code should never hold a raw handle directly.

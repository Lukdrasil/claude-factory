# S6667: Logging in a catch clause should pass the caught exception as a parameter

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-6667/

## Wrong

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Orders.Features.PlaceOrder;

internal sealed class PlaceOrderHandler(ILogger<PlaceOrderHandler> logger)
{
    public async Task HandleAsync(CancellationToken cancellationToken)
    {
        try
        {
            await SubmitAsync(cancellationToken);
        }
        catch (InvalidOperationException)
        {
            logger.LogError("Order submission failed."); // Noncompliant: exception not passed
            throw;
        }
    }

    private Task SubmitAsync(CancellationToken cancellationToken) => Task.CompletedTask;
}
```

## Right

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Orders.Features.PlaceOrder;

internal sealed class PlaceOrderHandler(ILogger<PlaceOrderHandler> logger)
{
    public async Task HandleAsync(CancellationToken cancellationToken)
    {
        try
        {
            await SubmitAsync(cancellationToken);
        }
        catch (InvalidOperationException exception)
        {
            logger.LogError(exception, "Order submission failed.");
            throw;
        }
    }

    private Task SubmitAsync(CancellationToken cancellationToken) => Task.CompletedTask;
}
```

**Principle**: dropping the caught exception from the log call discards the stack trace, type and inner exceptions needed to diagnose the failure; pass it as the logger's exception argument so the provider records it in structured form.

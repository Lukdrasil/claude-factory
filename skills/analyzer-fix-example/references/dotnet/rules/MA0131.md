# MA0131: ArgumentNullException.ThrowIfNull should not be used with non-nullable types

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0131.md

## Wrong

```csharp
namespace Kit.Orders.Application.Contracts;

internal static class OrderQuantityGuard
{
    public static void EnsureValid(int quantity)
    {
        ArgumentNullException.ThrowIfNull(quantity); // MA0131: int can never be null
    }
}
```

## Right

```csharp
namespace Kit.Orders.Application.Contracts;

internal static class OrderQuantityGuard
{
    public static void EnsureValid(int quantity)
    {
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(quantity);
    }
}
```

**Principle**: `ThrowIfNull` only guards against a null reference, which a value type can never be, so the check is dead code that hides the invariant the parameter actually needs enforced; here, that the quantity must be positive.

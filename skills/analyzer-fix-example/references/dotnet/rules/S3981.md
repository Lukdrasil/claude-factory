# S3981: Collection sizes and array length comparisons should make sense

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3981/

## Wrong

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal static class OrderLineValidator
{
    public static bool HasLines(IReadOnlyCollection<int> quantities) =>
        quantities.Count >= 0; // Noncompliant: Count can never be negative, so this is always true
}
```

## Right

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal static class OrderLineValidator
{
    public static bool HasLines(IReadOnlyCollection<int> quantities) =>
        quantities.Count > 0;
}
```

**Principle**: `Count`/`Length` on a collection can never be negative, so `>= 0` always evaluates to true and hides the real intent; `> 0` expresses the check the caller actually needs; "is not empty."

# MA0074: Avoid implicit culture-sensitive methods

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0074.md

## Wrong

```csharp
namespace Kit.Inventory.Application.Features.CreateProduct;

internal static class SkuValidator
{
    public static bool HasVendorPrefix(string sku, string prefix)
        => sku.StartsWith(prefix); // MA0074: implicit CurrentCulture comparison
}
```

## Right

```csharp
namespace Kit.Inventory.Application.Features.CreateProduct;

internal static class SkuValidator
{
    public static bool HasVendorPrefix(string sku, string prefix)
        => sku.StartsWith(prefix, StringComparison.Ordinal);
}
```

**Principle**: A SKU is a machine-format identifier, not user-facing text, so comparing it must not depend on the thread's current culture; passing `StringComparison.Ordinal` makes the comparison deterministic across machines and locales.

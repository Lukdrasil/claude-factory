# MA0012: Do not raise reserved exception type

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0012.md

## Wrong

```csharp
namespace Kit.Inventory.Application.Features.ReserveStock;

internal sealed class StockReserver
{
    public void Reserve(int? quantity)
    {
        if (quantity is null)
            throw new NullReferenceException("Quantity is required."); // MA0012: reserved exception type
    }
}
```

## Right

```csharp
namespace Kit.Inventory.Application.Features.ReserveStock;

internal sealed class StockReserver
{
    public void Reserve(int? quantity)
    {
        ArgumentNullException.ThrowIfNull(quantity);
    }
}
```

**Principle**: NullReferenceException, OutOfMemoryException and the other CLR-reserved exception types are meant to signal genuine runtime failures; code that catches them to detect a real crash would also catch this deliberate throw and misdiagnose it, whereas ArgumentNullException correctly reports an argument-validation failure.

# DDD002: Too many constructor dependencies

**Analyzer**: kit custom analyzer (analyzers/) · **Kit config**: warning · ddd_max_constructor_dependencies = 4 (default; 2 in Domain, 4 in Features) · **Docs**: analyzers/README.md

## Wrong

```csharp
namespace Acme.Features.Orders;

internal interface IOrderRepository { }
internal interface IPaymentGateway { }
internal interface IShippingCalculator { }
internal interface IInventoryService { }
internal interface INotificationSender { }

internal sealed class PlaceOrderHandler // marker: 5 injected dependencies, limit is 4
{
    public PlaceOrderHandler(
        IOrderRepository orders,
        IPaymentGateway payments,
        IShippingCalculator shipping,
        IInventoryService inventory,
        INotificationSender notifications)
    {
    }
}
```

## Right

```csharp
namespace Acme.Features.Orders;

internal interface IOrderRepository { }
internal interface IPaymentGateway { }
internal interface IOrderFulfillment { }

internal sealed class PlaceOrderHandler(
    IOrderRepository orders,
    IPaymentGateway payments,
    IOrderFulfillment fulfillment)
{
}
```

**Principle**: 5 injected dependencies → group the ones always used together (shipping, inventory, notifications) into one collaborator, `IOrderFulfillment`; this is an SRP proxy, a prompt to look, not a verdict.

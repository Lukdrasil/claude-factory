# MA0001: StringComparison is missing

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Info · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0001.md

## Wrong

```csharp
namespace Kit.Payments.Application.Features.ValidateCurrency;

internal sealed class CurrencyCodeValidator
{
    public bool IsSupported(string currencyCode) =>
        string.Equals(currencyCode, "EUR"); // MA0001: StringComparison missing
}
```

## Right

```csharp
namespace Kit.Payments.Application.Features.ValidateCurrency;

internal sealed class CurrencyCodeValidator
{
    public bool IsSupported(string currencyCode) =>
        string.Equals(currencyCode, "EUR", StringComparison.Ordinal);
}
```

**Principle**: string.Equals silently falls back to Ordinal comparison when the overload is omitted, which hides the actual comparison rule from the reader and from a future edit that might switch it to a culture-sensitive overload; passing StringComparison.Ordinal explicitly keeps the currency-code check deterministic on every machine and locale.

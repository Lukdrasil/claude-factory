# S1172: Unused method parameters should be removed

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-1172/

## Wrong

```csharp
namespace Kit.Billing.Features.ApplyDiscount;

internal sealed class DiscountCalculator
{
    private decimal Calculate(decimal amount, decimal taxRate) // "taxRate" unused
    {
        return amount * 0.9m;
    }
}
```

## Right

```csharp
namespace Kit.Billing.Features.ApplyDiscount;

internal sealed class DiscountCalculator
{
    private decimal Calculate(decimal amount)
    {
        return amount * 0.9m;
    }
}
```

**Principle**: A parameter the body never reads tells every caller that `taxRate` affects the discount when it does not; dropping it makes the signature an honest description of what the method depends on.

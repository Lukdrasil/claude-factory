# MA0009: Add regex evaluation timeout

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0009.md

## Wrong

```csharp
using System.Text.RegularExpressions;

namespace Kit.Identity.Application.Features.ValidateEmail;

internal static partial class EmailPattern
{
    [GeneratedRegex(@"^[^@\s]+@[^@\s]+\.[^@\s]+$")] // MA0009: timeout missing
    public static partial Regex Value();
}
```

## Right

```csharp
using System.Text.RegularExpressions;

namespace Kit.Identity.Application.Features.ValidateEmail;

internal static partial class EmailPattern
{
    [GeneratedRegex(@"^[^@\s]+@[^@\s]+\.[^@\s]+$", RegexOptions.None, matchTimeoutMilliseconds: 1000)]
    public static partial Regex Value();
}
```

**Principle**: A regex with no match timeout can be driven into catastrophic backtracking by attacker-supplied input (ReDoS); capping the evaluation time bounds the worst case so one crafted email address cannot hang a request thread.

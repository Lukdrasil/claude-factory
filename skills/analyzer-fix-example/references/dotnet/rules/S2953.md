# S2953: Methods named "Dispose" should implement "IDisposable.Dispose"

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2953/

## Wrong

```csharp
namespace Kit.Payments.Infrastructure;

internal sealed class PaymentGatewayClient
{
    private readonly HttpClient _httpClient;

    public PaymentGatewayClient(HttpClient httpClient) => _httpClient = httpClient;

    public void Dispose() // Noncompliant: named Dispose but the type isn't IDisposable
    {
        _httpClient.CancelPendingRequests();
    }
}
```

## Right

```csharp
namespace Kit.Payments.Infrastructure;

internal sealed class PaymentGatewayClient
{
    private readonly HttpClient _httpClient;

    public PaymentGatewayClient(HttpClient httpClient) => _httpClient = httpClient;

    public void CancelPendingRequests() => _httpClient.CancelPendingRequests();
}
```

**Principle**: a method named `Dispose` signals `IDisposable` semantics to callers, `using`/`await using`, and static analysis alike; naming it for what it actually does removes that false signal instead of forcing the type to implement an interface it doesn't need.

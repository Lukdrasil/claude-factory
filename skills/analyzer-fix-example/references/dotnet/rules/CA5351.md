# CA5351: Do Not Use Broken Cryptographic Algorithms

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured; disabled by default; must be opted into via `<AnalysisMode>` (Recommended/All) or an explicit severity in `.editorconfig` · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca5351

## Wrong

```csharp
using System.Security.Cryptography;

namespace Kit.Modules.Orders.Infrastructure.Caching;

internal sealed class OrderETagGenerator
{
    public string Compute(byte[] content)
    {
        using var md5 = MD5.Create(); // broken algorithm, subject to collision attacks
        return Convert.ToHexString(md5.ComputeHash(content));
    }
}
```

## Right

```csharp
using System.Security.Cryptography;

namespace Kit.Modules.Orders.Infrastructure.Caching;

internal sealed class OrderETagGenerator
{
    public string Compute(byte[] content) => Convert.ToHexString(SHA256.HashData(content));
}
```

**Principle**: SHA-2 family hashes such as SHA256 have no known practical collision attack, unlike MD5, so an ETag or integrity check derived from the hash can't be forged by a crafted collision.

# MA0006: Use String.Equals instead of equality operator

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0006.md

## Wrong

```csharp
namespace Kit.Orders.Application.Features.CheckOrderStatus;

internal sealed class OrderStatusChecker
{
    public bool IsCompleted(string status) => status == "Completed"; // MA0006: use string.Equals
}
```

## Right

```csharp
namespace Kit.Orders.Application.Features.CheckOrderStatus;

internal sealed class OrderStatusChecker
{
    public bool IsCompleted(string status) =>
        string.Equals(status, "Completed", StringComparison.Ordinal);
}
```

**Principle**: The == operator on strings compiles to a comparison whose rules are not visible at the call site; string.Equals with an explicit StringComparison states plainly that the order-status check is ordinal and case-sensitive.

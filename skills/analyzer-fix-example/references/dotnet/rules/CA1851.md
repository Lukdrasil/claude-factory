# CA1851: Possible multiple enumerations of `IEnumerable` collection

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA1851.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1851

## Wrong

```csharp
namespace Application.Features.BulkAssignTags;

internal sealed record AssignTagsCommand(IEnumerable<string> Tags);

internal sealed class AssignTagsHandler
{
    public void Handle(AssignTagsCommand command)
    {
        if (!command.Tags.Any()) return;
        foreach (var tag in command.Tags) // CA1851: 'Tags' enumerated more than once
        {
            Console.WriteLine(tag);
        }
    }
}
```

## Right

```csharp
namespace Application.Features.BulkAssignTags;

internal sealed record AssignTagsCommand(IEnumerable<string> Tags);

internal sealed class AssignTagsHandler
{
    public void Handle(AssignTagsCommand command)
    {
        var tags = command.Tags.ToList();
        if (tags.Count == 0) return;
        foreach (var tag in tags)
        {
            Console.WriteLine(tag);
        }
    }
}
```

**Principle**: Materializing the sequence once with `ToList()` guarantees the emptiness check and the `foreach` see the same items and pay the enumeration cost only once.

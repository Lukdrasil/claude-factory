# S5122: Cross-Origin Resource Sharing (CORS) policy should be restricted to trusted origins

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-5122/

## Wrong

```csharp
namespace Kit.Host;

internal static class CorsConfiguration
{
    public static void Configure(WebApplicationBuilder builder)
    {
        builder.Services.AddCors(options =>
        {
            options.AddDefaultPolicy(policy => policy.AllowAnyOrigin()); // Noncompliant
        });
    }
}
```

## Right

```csharp
namespace Kit.Host;

internal static class CorsConfiguration
{
    private static readonly string[] TrustedOrigins = ["https://app.example.com"];

    public static void Configure(WebApplicationBuilder builder)
    {
        builder.Services.AddCors(options =>
        {
            options.AddDefaultPolicy(policy => policy.WithOrigins(TrustedOrigins));
        });
    }
}
```

**Principle**: `AllowAnyOrigin()` (or reflecting the request's `Origin` header back unchecked) lets any website's script read authenticated responses from the API via the browser's CORS exception; enumerate the exact origins the API trusts with `WithOrigins(...)` instead.

**Layer note**: this is host/composition-root configuration in Infrastructure; Domain and Application have no equivalent concept of an HTTP origin.

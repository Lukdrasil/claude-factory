# MA0015: Specify the parameter name in ArgumentException

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0015.md

## Wrong

```csharp
namespace Kit.Shipping.Application.Features.CreateShipment;

internal sealed class ShipmentAddressValidator
{
    public void Validate(string city)
    {
        if (city.Length == 0)
            throw new ArgumentException("City is required."); // MA0015: paramName missing
    }
}
```

## Right

```csharp
namespace Kit.Shipping.Application.Features.CreateShipment;

internal sealed class ShipmentAddressValidator
{
    public void Validate(string city)
    {
        if (city.Length == 0)
            throw new ArgumentException("City is required.", paramName: nameof(city));
    }
}
```

**Principle**: Without paramName, a caller catching ArgumentException has no reliable way to know which argument failed short of parsing the message text; nameof(city) supplies that name and stays correct automatically if the parameter is ever renamed.

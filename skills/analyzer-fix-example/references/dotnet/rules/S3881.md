# S3881: "IDisposable" should be implemented correctly

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3881/

## Wrong

```csharp
namespace Kit.Files.Infrastructure;

public class TempFileHandle : IDisposable
{
    private readonly string _path;

    public TempFileHandle(string path) => _path = path;

    public void Dispose() // Noncompliant: not sealed, and no protected virtual Dispose(bool) for derived types
    {
        File.Delete(_path);
    }
}
```

## Right

```csharp
namespace Kit.Files.Infrastructure;

public class TempFileHandle : IDisposable
{
    private readonly string _path;
    private bool _disposed;

    public TempFileHandle(string path) => _path = path;

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    protected virtual void Dispose(bool disposing)
    {
        if (_disposed) return;
        if (disposing) File.Delete(_path);
        _disposed = true;
    }
}
```

**Principle**: the public `Dispose()` plus `protected virtual Dispose(bool)` pair lets a derived class add its own cleanup by overriding `Dispose(bool)` without hiding the base type's release logic.

**Layer note**: this pattern is only needed for a type meant to be a base for other Infrastructure adapters; a leaf adapter that will never be subclassed should follow the kit's `internal sealed` default and expose a plain, non-virtual `Dispose()` instead.

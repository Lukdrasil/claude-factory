# DDD001: Aggregate root exposes a public setter

**Analyzer**: kit custom analyzer (analyzers/) · **Kit config**: warning · ddd_aggregate_base_types = AggregateRoot,Entity (configurable per folder) · **Docs**: analyzers/README.md

## Wrong

```csharp
namespace Acme.Domain.Orders;

public abstract class AggregateRoot
{
}

public sealed class Order : AggregateRoot
{
    public OrderStatus Status { get; set; } // marker: public setter on aggregate root

    public Order(OrderStatus status)
    {
        Status = status;
    }
}

public enum OrderStatus { Placed, Shipped, Canceled }
```

## Right

```csharp
namespace Acme.Domain.Orders;

public abstract class AggregateRoot
{
}

public sealed class Order : AggregateRoot
{
    public OrderStatus Status { get; private set; }

    public Order(OrderStatus status)
    {
        Status = status;
    }

    public void Ship()
    {
        if (Status != OrderStatus.Placed)
            throw new InvalidOperationException("Only a placed order can ship.");

        Status = OrderStatus.Shipped;
    }
}

public enum OrderStatus { Placed, Shipped, Canceled }
```

**Principle**: aggregate invariants live in domain methods; `Ship()` is the only path allowed to move `Status` forward, so the rules about legal transitions can't be bypassed by an outside caller setting the property directly.

# MA0056: Do not call overridable members in constructor

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0056.md

## Wrong

```csharp
namespace Kit.Billing.Infrastructure.Gateways;

internal abstract class PaymentGatewayBase
{
    protected PaymentGatewayBase()
    {
        Initialize(); // MA0056: overridable member called in constructor
    }

    protected virtual void Initialize() { }
}

internal sealed class StripeGateway : PaymentGatewayBase
{
    private readonly List<string> _log = [];

    protected override void Initialize() => _log.Add("initialized"); // _log is still null here
}
```

## Right

```csharp
namespace Kit.Billing.Infrastructure.Gateways;

internal abstract class PaymentGatewayBase
{
    public static T Create<T>() where T : PaymentGatewayBase, new()
    {
        var gateway = new T();
        gateway.Initialize();
        return gateway;
    }

    protected virtual void Initialize() { }
}

internal sealed class StripeGateway : PaymentGatewayBase
{
    private readonly List<string> _log = [];

    protected override void Initialize() => _log.Add("initialized");
}
```

**Principle**: A virtual call made from a base constructor runs before the derived class's own field initializers and constructor body execute, so the override observes a half-built object; running Initialize from a factory method after new T() completes lets it see StripeGateway fully constructed.

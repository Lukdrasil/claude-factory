# CA1815: Override equals and operator equals on value types

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: warning in Domain · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1815

## Wrong

```csharp
namespace Kit.Modules.Orders.Domain;

internal readonly struct Money // no Equals/== override: falls back to reflection-based comparison
{
    public Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }

    public decimal Amount { get; }
    public string Currency { get; }
}
```

## Right

```csharp
namespace Kit.Modules.Orders.Domain;

internal readonly record struct Money(decimal Amount, string Currency);
```

**Principle**: A `readonly record struct` gets compiler-generated `Equals`, `GetHashCode`, and `==`/`!=` on every field, avoiding the reflection-based comparison `ValueType.Equals` falls back to when domain value objects are compared or used as dictionary keys.

**Layer note**: The kit enables CA1815 as a warning only in Domain, where value objects like `Money` are routinely compared, sorted, or used as keys; value types elsewhere don't carry the same severity.

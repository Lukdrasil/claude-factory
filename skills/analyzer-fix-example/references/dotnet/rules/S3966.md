# S3966: Objects should not be disposed more than once

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3966/

## Wrong

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportExporter
{
    public async Task ExportAsync(string path, string content, CancellationToken cancellationToken)
    {
        var writer = new StreamWriter(path);
        await using (writer) // Noncompliant: writer is disposed again below
        {
            await writer.WriteAsync(content.AsMemory(), cancellationToken);
        }

        await writer.DisposeAsync();
    }
}
```

## Right

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportExporter
{
    public async Task ExportAsync(string path, string content, CancellationToken cancellationToken)
    {
        await using var writer = new StreamWriter(path);
        await writer.WriteAsync(content.AsMemory(), cancellationToken);
    }
}
```

**Principle**: each disposable should have exactly one owner responsible for exactly one disposal call; a single `await using` declaration both scopes and disposes the resource once, removing the redundant explicit call.

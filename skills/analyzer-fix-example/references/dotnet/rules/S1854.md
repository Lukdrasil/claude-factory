# S1854: Unused assignments should be removed

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-1854/

## Wrong

```csharp
namespace Kit.Payments.Features.RetryPayment;

internal sealed class RetryBudget
{
    public int ComputeDelaySeconds(int attempt)
    {
        var delay = 1;          // Noncompliant: overwritten before use
        delay = attempt * 2;    // Noncompliant: overwritten before use
        delay = attempt * 5;
        return delay;
    }
}
```

## Right

```csharp
namespace Kit.Payments.Features.RetryPayment;

internal sealed class RetryBudget
{
    public int ComputeDelaySeconds(int attempt)
    {
        var delay = attempt * 5;
        return delay;
    }
}
```

**Principle**: Two assignments to `delay` are discarded before either value is ever read; keeping only the assignment that survives to the `return` removes work the CPU does and the reader has to trace for nothing.

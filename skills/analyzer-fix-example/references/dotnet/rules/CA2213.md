# CA2213: Disposable fields should be disposed

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA2213.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca2213

## Wrong

```csharp
namespace Infrastructure.Messaging;

internal sealed class OutboxPublisher : IDisposable
{
    private readonly Timer _flushTimer = new(_ => { }, null, 0, 5000); // CA2213: never disposed
    private readonly HttpClient _httpClient = new();

    public void Dispose()
    {
        _httpClient.Dispose();
    }
}
```

## Right

```csharp
namespace Infrastructure.Messaging;

internal sealed class OutboxPublisher : IDisposable
{
    private readonly Timer _flushTimer = new(_ => { }, null, 0, 5000);
    private readonly HttpClient _httpClient = new();

    public void Dispose()
    {
        _flushTimer.Dispose();
        _httpClient.Dispose();
    }
}
```

**Principle**: Every disposable field the class constructs is a resource it owns, so `Dispose()` must release all of them, not just the one that happened to be added last.

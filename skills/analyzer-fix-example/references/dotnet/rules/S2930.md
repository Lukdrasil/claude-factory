# S2930: "IDisposables" should be disposed

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2930/

## Wrong

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportExporter
{
    public void Export(string path, string content)
    {
        var writer = new StreamWriter(path); // Noncompliant: never disposed
        writer.Write(content);
    }
}
```

## Right

```csharp
namespace Kit.Reporting.Infrastructure;

internal sealed class ReportExporter
{
    public async Task ExportAsync(string path, string content, CancellationToken cancellationToken)
    {
        await using var writer = new StreamWriter(path);
        await writer.WriteAsync(content.AsMemory(), cancellationToken);
    }
}
```

**Principle**: `await using` ties the writer's lifetime to the method scope so the underlying file handle is released deterministically even if the write throws or the call is cancelled.

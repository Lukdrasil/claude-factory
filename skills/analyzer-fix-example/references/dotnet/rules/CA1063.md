# CA1063: Implement IDisposable correctly

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA1063.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1063

## Wrong

```csharp
namespace Infrastructure.Persistence;

public sealed class LeaseTokenStore : IDisposable
{
    private readonly FileStream _handle = new("lease.tok", FileMode.OpenOrCreate);

    void IDisposable.Dispose() // CA1063: Dispose() must be public, not explicit
    {
        _handle.Dispose();
    }
}
```

## Right

```csharp
namespace Infrastructure.Persistence;

public sealed class LeaseTokenStore : IDisposable
{
    private readonly FileStream _handle = new("lease.tok", FileMode.OpenOrCreate);
    private bool _disposed;

    public void Dispose()
    {
        if (_disposed) return;
        _handle.Dispose();
        _disposed = true;
    }
}
```

**Principle**: A sealed type has no subclass to extend `Dispose`, so a single public, non-virtual `Dispose()` that disposes owned resources directly is the entire contract; no `Dispose(bool)`, no finalizer, no explicit interface implementation hiding it.

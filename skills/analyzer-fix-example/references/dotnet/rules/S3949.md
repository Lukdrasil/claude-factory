# S3949: Calculations should not overflow

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3949/

## Wrong

```csharp
namespace Kit.Orders.Domain;

public static class InvoiceTotals
{
    public static int TotalCents(int unitPriceCents, int quantity)
    {
        return unitPriceCents * quantity; // Noncompliant: int * int can overflow silently
    }
}
```

## Right

```csharp
namespace Kit.Orders.Domain;

public static class InvoiceTotals
{
    public static long TotalCents(int unitPriceCents, int quantity)
    {
        checked
        {
            return (long)unitPriceCents * quantity;
        }
    }
}
```

**Principle**: widening to `long` and wrapping the multiplication in a `checked` block turns a silent wraparound into an `OverflowException` at the point of failure, instead of a corrupted total surfacing further downstream.

# MA0002: IEqualityComparer<string> or IComparer<string> is missing

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0002.md

## Wrong

```csharp
namespace Kit.Catalog.Application.Features.DeduplicateSkus;

internal sealed class SkuDeduplicator
{
    public HashSet<string> Deduplicate(IEnumerable<string> skus) =>
        new HashSet<string>(skus); // MA0002: comparer missing
}
```

## Right

```csharp
namespace Kit.Catalog.Application.Features.DeduplicateSkus;

internal sealed class SkuDeduplicator
{
    public HashSet<string> Deduplicate(IEnumerable<string> skus) =>
        new HashSet<string>(skus, StringComparer.Ordinal);
}
```

**Principle**: HashSet<string> without an explicit comparer falls back to the platform's default string comparer, which can be culture-sensitive; passing StringComparer.Ordinal makes SKU deduplication produce the same result regardless of the machine's locale.

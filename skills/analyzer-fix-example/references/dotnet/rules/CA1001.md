# CA1001: Types that own disposable fields should be disposable

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA1001.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1001

## Wrong

```csharp
using System.Text;

namespace Application.Features.ExportInvoices;

internal sealed class InvoiceExportHandler // CA1001: owns a disposable field, isn't IDisposable
{
    private readonly FileStream _output = new("export.csv", FileMode.Create);

    public void Append(string line) => _output.Write(System.Text.Encoding.UTF8.GetBytes(line));
}
```

## Right

```csharp
using System.Text;

namespace Application.Features.ExportInvoices;

internal sealed class InvoiceExportHandler : IDisposable
{
    private readonly FileStream _output = new("export.csv", FileMode.Create);

    public void Append(string line) => _output.Write(System.Text.Encoding.UTF8.GetBytes(line));

    public void Dispose() => _output.Dispose();
}
```

**Principle**: Implementing `IDisposable` on the owning type gives callers one place to release everything the type acquired, instead of leaving the field's lifetime unmanaged.

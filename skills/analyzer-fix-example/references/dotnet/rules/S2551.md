# S2551: Shared resources should not be used for locking

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2551/

## Wrong

```csharp
namespace Kit.Inventory.Infrastructure.Stock;

internal sealed class StockAdjuster
{
    public void Adjust(Action adjustment)
    {
        lock (this) // Noncompliant: publicly reachable instance used as lock
        {
            adjustment();
        }
    }
}
```

## Right

```csharp
namespace Kit.Inventory.Infrastructure.Stock;

internal sealed class StockAdjuster
{
    private readonly Lock _gate = new();

    public void Adjust(Action adjustment)
    {
        lock (_gate)
        {
            adjustment();
        }
    }
}
```

**Principle**: `lock (this)` locks on an object callers outside the class can also see and lock on; a second component synchronizing on the same `StockAdjuster` instance for an unrelated reason silently blocks this one; a private `Lock` field can never be reached from outside the class, so no other code can accidentally contend on it.

# S2743: Static fields should not be used in generic types

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2743/

## Wrong

```csharp
namespace Kit.Shared.Infrastructure.Caching;

internal class TypedCache<T>
{
    protected static readonly Dictionary<string, T> Entries = []; // Noncompliant: not shared across T

    public static void Set(string key, T value) => Entries[key] = value;
}
```

## Right

```csharp
namespace Kit.Shared.Infrastructure.Caching;

internal abstract class TypedCacheBase
{
    protected static readonly Dictionary<(Type Type, string Key), object?> Entries = [];
}

internal sealed class TypedCache<T> : TypedCacheBase
{
    public static void Set(string key, T value) => Entries[(typeof(T), key)] = value;
}
```

**Principle**: `TypedCache<int>.Entries` and `TypedCache<string>.Entries` are two separate dictionaries even though the field reads as one shared cache; moving the static state to a non-generic base class makes the sharing the field's name implies actually true.

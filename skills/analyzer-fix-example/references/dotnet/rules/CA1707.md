# CA1707: Identifiers should not contain underscores

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: default; none in test projects · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1707

## Wrong

```csharp
namespace Kit.Modules.Billing.Application.Contracts;

internal sealed record Invoice_Summary(Guid Customer_Id, decimal Total_Amount); // underscored identifiers
```

## Right

```csharp
namespace Kit.Modules.Billing.Application.Contracts;

internal sealed record InvoiceSummary(Guid CustomerId, decimal TotalAmount);
```

**Principle**: Removing underscores keeps public API naming consistent with the rest of the BCL and the kit's own conventions, so consumers don't have to learn two casing styles.

**Layer note**: The kit disables CA1707 in test projects; `Method_Should_Do_Thing` names stay allowed there because underscores are idiomatic xUnit test naming and read as a sentence better than PascalCase would.

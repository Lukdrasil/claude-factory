# MA0134: Observe result of async calls

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0134.md

## Wrong

```csharp
namespace Kit.Notifications.Application.Features.NotifyCustomer;

internal sealed class CustomerNotifier
{
    public void Notify(string email, CancellationToken cancellationToken)
    {
        SendAsync(email, cancellationToken); // MA0134: awaitable result not observed
    }

    private Task SendAsync(string email, CancellationToken cancellationToken) => Task.CompletedTask;
}
```

## Right

```csharp
namespace Kit.Notifications.Application.Features.NotifyCustomer;

internal sealed class CustomerNotifier
{
    public async Task NotifyAsync(string email, CancellationToken cancellationToken)
    {
        await SendAsync(email, cancellationToken);
    }

    private Task SendAsync(string email, CancellationToken cancellationToken) => Task.CompletedTask;
}
```

**Principle**: An un-awaited task's exceptions and completion are never observed by the caller and surface later as an unobserved task exception, if at all; awaiting it, with the `CancellationToken` threaded all the way through, surfaces failures where the call happens.

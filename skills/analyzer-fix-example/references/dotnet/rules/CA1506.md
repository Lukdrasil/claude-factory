# CA1506: Avoid excessive class coupling

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: warning in Domain; none in Infrastructure and tests · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1506

## Wrong

```csharp
namespace Kit.Modules.Orders.Domain;

internal sealed class OrderPricingPolicy( // couples directly to every calculator in the module
    ITaxCalculator tax,
    IDiscountEngine discounts,
    ICurrencyConverter currency,
    IShippingCalculator shipping,
    ILoyaltyPointsCalculator loyalty,
    IFraudScorer fraud)
{
    public Money Price(Order order) =>
        tax.Apply(discounts.Apply(currency.Convert(shipping.Add(order.Subtotal))));
}

internal interface ITaxCalculator { Money Apply(Money amount); }
internal interface IDiscountEngine { Money Apply(Money amount); }
internal interface ICurrencyConverter { Money Convert(Money amount); }
internal interface IShippingCalculator { Money Add(Money amount); }
internal interface ILoyaltyPointsCalculator;
internal interface IFraudScorer;
internal sealed record Money(decimal Amount);
internal sealed record Order(Money Subtotal);
```

## Right

```csharp
namespace Kit.Modules.Orders.Domain;

internal sealed class OrderPricingPolicy(IPricingEngine pricingEngine)
{
    public Money Price(Order order) => pricingEngine.Compute(order);
}

internal interface IPricingEngine
{
    Money Compute(Order order);
}

internal sealed record Money(decimal Amount);
internal sealed record Order(Money Subtotal);
```

**Principle**: Grouping the calculators the domain always uses together behind one `IPricingEngine` seam collapses six direct dependencies into one, restoring low coupling without losing the individual calculators; they still exist behind the seam in Infrastructure.

**Layer note**: The kit enables CA1506 as a warning only in Domain, where high coupling signals a class doing too much. Infrastructure adapters that legitimately wire up many downstream clients, and test fixtures composing many collaborators, are exempt (severity none).

# IDE0040: Add accessibility modifiers

**Analyzer**: IDE built-in · **Kit config**: warning (accessibility modifiers required) · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/style-rules/ide0040

## Wrong

```csharp
namespace Acme.Features.Orders;

sealed class OrderCanceledHandler // marker: no accessibility modifier
{
    void Handle(int orderId) { }
}
```

## Right

```csharp
namespace Acme.Features.Orders;

internal sealed class OrderCanceledHandler
{
    private void Handle(int orderId) { }
}
```

**Principle**: an explicit accessibility modifier on every declaration states its intended surface, so no reader has to fall back on C#'s default to know who can call it.

# MA0022: Return Task.FromResult instead of returning null

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: Warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0022.md

## Wrong

```csharp
namespace Kit.Catalog.Application.Ports;

internal interface IProductCache
{
    Task<Product?> GetAsync(string sku, CancellationToken cancellationToken);
}

internal sealed class NoOpProductCache : IProductCache
{
    public Task<Product?> GetAsync(string sku, CancellationToken cancellationToken)
    {
        return null; // MA0022: null Task reference, not a completed task
    }
}

public sealed record Product(string Sku, string Name);
```

## Right

```csharp
namespace Kit.Catalog.Application.Ports;

internal interface IProductCache
{
    Task<Product?> GetAsync(string sku, CancellationToken cancellationToken);
}

internal sealed class NoOpProductCache : IProductCache
{
    public Task<Product?> GetAsync(string sku, CancellationToken cancellationToken) =>
        Task.FromResult<Product?>(null);
}

public sealed record Product(string Sku, string Name);
```

**Principle**: A method typed Task<T> that returns the null reference instead of a completed task throws a NullReferenceException the instant a caller awaits it; Task.FromResult(null) returns an actual completed task carrying a null value, which is what an awaiting caller expects to receive.

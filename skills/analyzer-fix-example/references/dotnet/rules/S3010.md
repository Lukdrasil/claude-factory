# S3010: Static fields should not be updated in constructors

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3010/

## Wrong

```csharp
namespace Kit.Customers.Domain;

public sealed class Customer
{
    private static DateOnly s_registeredOn;

    public Customer(DateOnly registeredOn)
    {
        s_registeredOn = registeredOn; // Noncompliant: overwrites the value for every Customer instance
    }

    public DateOnly RegisteredOn => s_registeredOn;
}
```

## Right

```csharp
namespace Kit.Customers.Domain;

public sealed class Customer
{
    public Customer(DateOnly registeredOn) => RegisteredOn = registeredOn;

    public DateOnly RegisteredOn { get; }
}
```

**Principle**: a static field is shared by every instance of the type, so assigning it from an instance constructor makes every existing and future `Customer` report the most recently constructed one's registration date; making it an instance property gives each object its own state.

# S6664: The code block contains too many logging calls

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-6664/

## Wrong

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Orders.Features.PlaceOrder;

internal sealed record OrderLine(string Sku);

internal sealed class PlaceOrderHandler(ILogger<PlaceOrderHandler> logger)
{
    public async Task HandleAsync(IReadOnlyList<OrderLine> lines, CancellationToken cancellationToken)
    {
        foreach (OrderLine line in lines)
        {
            logger.LogInformation("Processing {Sku}", line.Sku); // Noncompliant: 2nd Information call in this block
            await ReserveAsync(line, cancellationToken);
            logger.LogInformation("Reserved {Sku}", line.Sku);
        }
    }

    private Task ReserveAsync(OrderLine line, CancellationToken cancellationToken) => Task.CompletedTask;
}
```

## Right

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Orders.Features.PlaceOrder;

internal sealed record OrderLine(string Sku);

internal sealed class PlaceOrderHandler(ILogger<PlaceOrderHandler> logger)
{
    public async Task HandleAsync(IReadOnlyList<OrderLine> lines, CancellationToken cancellationToken)
    {
        foreach (OrderLine line in lines)
        {
            await ReserveAsync(line, cancellationToken);
            logger.LogInformation("Reserved {Sku}", line.Sku);
        }
    }

    private Task ReserveAsync(OrderLine line, CancellationToken cancellationToken) => Task.CompletedTask;
}
```

**Principle**: two Information-level log calls per loop iteration doubles log volume without adding diagnostic value; keep the call that records the outcome and drop the one that only echoes an input already implied by it.

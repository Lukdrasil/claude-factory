# S2222: Locks should be released on all paths

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-2222/

## Wrong

```csharp
namespace Kit.Catalog.Infrastructure.Caching;

internal sealed class ProductCache
{
    private readonly Lock _gate = new();
    private readonly Dictionary<Guid, string> _entries = [];

    public string? TryGet(Guid productId, bool skipMissing)
    {
        _gate.Enter(); // Noncompliant: not released on every path
        if (skipMissing && !_entries.ContainsKey(productId))
        {
            return null;
        }

        var value = _entries.GetValueOrDefault(productId);
        _gate.Exit();
        return value;
    }
}
```

## Right

```csharp
namespace Kit.Catalog.Infrastructure.Caching;

internal sealed class ProductCache
{
    private readonly Lock _gate = new();
    private readonly Dictionary<Guid, string> _entries = [];

    public string? TryGet(Guid productId, bool skipMissing)
    {
        lock (_gate)
        {
            if (skipMissing && !_entries.ContainsKey(productId))
            {
                return null;
            }

            return _entries.GetValueOrDefault(productId);
        }
    }
}
```

**Principle**: The early `return null` skips `_gate.Exit()`, leaving the lock held forever and deadlocking the next caller; a `lock` block releases on every exit path, including early returns and thrown exceptions, so the invariant can't be missed by hand.

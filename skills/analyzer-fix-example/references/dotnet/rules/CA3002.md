# CA3002: Review code for XSS vulnerabilities

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured; disabled by default; a dataflow/security rule that must be opted into via `<AnalysisMode>` (Recommended/All) or an explicit severity in `.editorconfig` · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca3002

## Wrong

```csharp
namespace Kit.Modules.Orders.Application.Features.OrderReceipt;

internal static class OrderReceiptEndpoint
{
    internal static IResult Handle(string customerNote)
    {
        var html = $"<html><body>Note: {customerNote}</body></html>"; // raw user input embedded in HTML
        return Results.Content(html, "text/html");
    }
}
```

## Right

```csharp
using System.Net;

namespace Kit.Modules.Orders.Application.Features.OrderReceipt;

internal static class OrderReceiptEndpoint
{
    internal static IResult Handle(string customerNote)
    {
        var html = $"<html><body>Note: {WebUtility.HtmlEncode(customerNote)}</body></html>";
        return Results.Content(html, "text/html");
    }
}
```

**Principle**: HTML-encoding untrusted input before it's embedded in markup turns `<`, `>`, `&`, and quotes into their character-reference equivalents, so the browser renders them as text instead of executing them as markup or script.

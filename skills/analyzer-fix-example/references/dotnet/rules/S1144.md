# S1144: Unused private types or members should be removed

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-1144/

## Wrong

```csharp
namespace Kit.Catalog.Features.RenameProduct;

internal sealed record RenameProductCommand(Guid ProductId, string NewName);

internal sealed class RenameProductHandler
{
    public void Handle(RenameProductCommand command)
    {
        Console.WriteLine(command.NewName);
    }

    private static string Normalize(string name) => name.Trim(); // never called
}
```

## Right

```csharp
namespace Kit.Catalog.Features.RenameProduct;

internal sealed record RenameProductCommand(Guid ProductId, string NewName);

internal sealed class RenameProductHandler
{
    public void Handle(RenameProductCommand command)
    {
        Console.WriteLine(command.NewName);
    }
}
```

**Principle**: A private method nobody calls carries no test coverage and no caller to prove it still works; deleting it removes a piece of surface area a future edit could silently break.

# CA1065: Do not raise exceptions in unexpected locations

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA1065.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1065

## Wrong

```csharp
namespace Domain.Orders;

public sealed class Order
{
    private readonly List<OrderLine> _lines = [];

    public OrderLine FirstLine // CA1065: property getter throws
    {
        get
        {
            if (_lines.Count == 0)
            {
                throw new InvalidOperationException("Order has no lines.");
            }
            return _lines[0];
        }
    }
}

public sealed record OrderLine(string Sku, int Quantity);
```

## Right

```csharp
namespace Domain.Orders;

public sealed class Order
{
    private readonly List<OrderLine> _lines = [];

    public bool TryGetFirstLine(out OrderLine? line)
    {
        line = _lines.Count > 0 ? _lines[0] : null;
        return line is not null;
    }
}

public sealed record OrderLine(string Sku, int Quantity);
```

**Principle**: A property getter behaves like a field read with no exceptions, so a missing-value case becomes a `Try*` method instead of a thrown exception.

**Layer note**: Domain entities express "might not exist" through `Try*` methods or nullable returns, since aggregate invariants are enforced at command boundaries, not at read time.

# IDE0005: Remove unnecessary import

**Analyzer**: IDE built-in · **Kit config**: warning (unused usings) · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/style-rules/ide0005

## Wrong

```csharp
using System;
using System.Text; // marker: unused using

namespace Acme.Features.Orders;

internal sealed class OrderSummaryFormatter
{
    public string Format(int orderId) => $"Order #{orderId}";
}
```

## Right

```csharp
using System;

namespace Acme.Features.Orders;

internal sealed class OrderSummaryFormatter
{
    public string Format(int orderId) => $"Order #{orderId}";
}
```

**Principle**: an unused using widens the file's apparent dependency surface, so trimming it keeps that surface honest for the next reader.

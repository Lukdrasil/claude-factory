# MA0100: Await task before disposing of resources

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0100.md

## Wrong

```csharp
namespace Kit.Notifications.Infrastructure;

internal sealed class EmailSender
{
    public Task SendAsync(string to, CancellationToken cancellationToken)
    {
        using var client = new SmtpClientStub();
        return client.SendAsync(to, cancellationToken); // MA0100: disposes before the task completes
    }
}

internal sealed class SmtpClientStub : IDisposable
{
    public Task SendAsync(string to, CancellationToken cancellationToken) => Task.CompletedTask;
    public void Dispose() { }
}
```

## Right

```csharp
namespace Kit.Notifications.Infrastructure;

internal sealed class EmailSender
{
    public async Task SendAsync(string to, CancellationToken cancellationToken)
    {
        using var client = new SmtpClientStub();
        await client.SendAsync(to, cancellationToken);
    }
}

internal sealed class SmtpClientStub : IDisposable
{
    public Task SendAsync(string to, CancellationToken cancellationToken) => Task.CompletedTask;
    public void Dispose() { }
}
```

**Principle**: Returning the task lets the `using` block dispose `client` as soon as the method returns, not when the send finishes, so the operation can keep running against an already-disposed resource; awaiting it keeps the resource alive for the whole operation.

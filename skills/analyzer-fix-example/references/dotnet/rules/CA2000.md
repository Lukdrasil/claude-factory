# CA2000: Dispose objects before losing scope

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA2000.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca2000

## Wrong

```csharp
namespace Infrastructure.Documents;

internal sealed class ContractReader
{
    public async Task<string> ReadHeaderAsync(string path, CancellationToken cancellationToken)
    {
        var stream = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.Read, 4096, useAsync: true); // CA2000: leaked if ReadHeaderCoreAsync throws
        return await ReadHeaderCoreAsync(stream, cancellationToken);
    }

    private static async Task<string> ReadHeaderCoreAsync(FileStream stream, CancellationToken cancellationToken)
    {
        var buffer = new byte[4];
        await stream.ReadAsync(buffer, cancellationToken);
        return stream.Name;
    }
}
```

## Right

```csharp
namespace Infrastructure.Documents;

internal sealed class ContractReader
{
    public async Task<string> ReadHeaderAsync(string path, CancellationToken cancellationToken)
    {
        await using var stream = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.Read, 4096, useAsync: true);
        return await ReadHeaderCoreAsync(stream, cancellationToken);
    }

    private static async Task<string> ReadHeaderCoreAsync(FileStream stream, CancellationToken cancellationToken)
    {
        var buffer = new byte[4];
        await stream.ReadAsync(buffer, cancellationToken);
        return stream.Name;
    }
}
```

**Principle**: `await using` releases the file handle on every exit path, success, exception, or cancellation, instead of depending on a caller that might never get the chance to dispose it.

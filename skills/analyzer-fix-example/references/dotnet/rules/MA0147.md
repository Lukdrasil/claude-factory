# MA0147: Avoid async void method for delegate

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0147.md

## Wrong

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class OrderNotifier
{
    public OrderNotifier(OrderEventBus bus)
        => bus.Subscribe(async orderId => await NotifyAsync(orderId)); // MA0147: async lambda bound to a void delegate

    private static Task NotifyAsync(Guid orderId) => Task.CompletedTask;
}

internal sealed class OrderEventBus
{
    public void Subscribe(Action<Guid> handler) { }
}
```

## Right

```csharp
namespace Kit.Orders.Application.Features.PlaceOrder;

internal sealed class OrderNotifier
{
    public OrderNotifier(OrderEventBus bus)
        => bus.Subscribe(orderId => NotifyAsync(orderId));

    private static Task NotifyAsync(Guid orderId) => Task.CompletedTask;
}

internal sealed class OrderEventBus
{
    public void Subscribe(Func<Guid, Task> handler) { }
}
```

**Principle**: An async lambda passed to an `Action<T>` compiles into an async void delegate, so any exception it throws cannot be awaited or caught by `OrderEventBus`; exposing `Func<Guid, Task>` instead keeps the returned task observable by the subscriber.

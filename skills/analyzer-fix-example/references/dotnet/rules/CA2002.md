# CA2002: Do not lock on objects with weak identity

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured, off by default; enable via dotnet_diagnostic.CA2002.severity = warning · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca2002

## Wrong

```csharp
namespace Infrastructure.Caching;

internal sealed class ExchangeRateCache
{
    private readonly Dictionary<string, decimal> _rates = [];

    public void Set(string currencyPair, decimal rate)
    {
        lock (this) // CA2002: locking on 'this' has weak identity
        {
            _rates[currencyPair] = rate;
        }
    }
}
```

## Right

```csharp
namespace Infrastructure.Caching;

internal sealed class ExchangeRateCache
{
    private readonly Lock _gate = new();
    private readonly Dictionary<string, decimal> _rates = [];

    public void Set(string currencyPair, decimal rate)
    {
        lock (_gate)
        {
            _rates[currencyPair] = rate;
        }
    }
}
```

**Principle**: The lock target is a private, dedicated `System.Threading.Lock` field inaccessible outside the class, so no external code can ever contend on the same monitor and cause an unrelated deadlock.

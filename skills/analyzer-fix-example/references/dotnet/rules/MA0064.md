# MA0064: Avoid locking on publicly accessible instance

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: warning · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0064.md

## Wrong

```csharp
namespace Kit.Inventory.Infrastructure;

internal sealed class StockCache
{
    private int _hits;

    public void RecordHit()
    {
        lock (this) // MA0064: locking on a reachable instance
        {
            _hits++;
        }
    }
}
```

## Right

```csharp
namespace Kit.Inventory.Infrastructure;

using System.Threading;

internal sealed class StockCache
{
    private readonly Lock _sync = new();
    private int _hits;

    public void RecordHit()
    {
        lock (_sync)
        {
            _hits++;
        }
    }
}
```

**Principle**: Any code that can obtain a reference to `this` can lock on it too, so an unrelated caller can create contention or a deadlock this class never intended; a private `Lock` field that never escapes the type removes that possibility.

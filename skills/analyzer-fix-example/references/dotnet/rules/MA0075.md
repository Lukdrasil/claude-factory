# MA0075: Do not use implicit culture-sensitive ToString

**Analyzer**: Meziantou.Analyzer · **Kit config**: not configured; analyzer default: info · **Docs**: https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0075.md

## Wrong

```csharp
namespace Kit.Billing.Application.Features.GenerateInvoice;

internal sealed class InvoiceLineFormatter
{
    public string FormatAdjustment(int cents)
        => "Adjustment: " + cents; // MA0075: implicit culture-sensitive ToString
}
```

## Right

```csharp
namespace Kit.Billing.Application.Features.GenerateInvoice;

using System.Globalization;

internal sealed class InvoiceLineFormatter
{
    public string FormatAdjustment(int cents)
        => "Adjustment: " + cents.ToString(CultureInfo.InvariantCulture);
}
```

**Principle**: The implicit `ToString()` inserted by string concatenation formats the number using the thread's current culture, so the same code can render a different string per user; formatting with `CultureInfo.InvariantCulture` makes the output stable regardless of where it runs.

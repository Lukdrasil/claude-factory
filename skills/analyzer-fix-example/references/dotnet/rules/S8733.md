# S8733: Potential Cartesian Explosion

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-8733/

## Wrong

```csharp
using Microsoft.EntityFrameworkCore;

namespace Kit.Enrollment.Infrastructure;

internal sealed class Enrollment { public Guid StudentId { get; init; } }
internal sealed class Announcement { public string Text { get; init; } = ""; }
internal sealed class Course { public List<Enrollment> Enrollments { get; init; } = []; public List<Announcement> Announcements { get; init; } = []; }
internal sealed class CourseDbContext : DbContext { public DbSet<Course> Courses => Set<Course>(); }

internal sealed class CourseRepository(CourseDbContext dbContext)
{
    public Task<List<Course>> GetWithDetailsAsync(CancellationToken cancellationToken) =>
        dbContext.Courses
            .Include(c => c.Enrollments)
            .Include(c => c.Announcements) // Noncompliant: sibling collections joined, rows multiply
            .ToListAsync(cancellationToken);
}
```

## Right

```csharp
using Microsoft.EntityFrameworkCore;

namespace Kit.Enrollment.Infrastructure;

internal sealed class Enrollment { public Guid StudentId { get; init; } }
internal sealed class Announcement { public string Text { get; init; } = ""; }
internal sealed class Course { public List<Enrollment> Enrollments { get; init; } = []; public List<Announcement> Announcements { get; init; } = []; }
internal sealed class CourseDbContext : DbContext { public DbSet<Course> Courses => Set<Course>(); }

internal sealed class CourseRepository(CourseDbContext dbContext)
{
    public Task<List<Course>> GetWithDetailsAsync(CancellationToken cancellationToken) =>
        dbContext.Courses
            .Include(c => c.Enrollments)
            .Include(c => c.Announcements)
            .AsSplitQuery()
            .ToListAsync(cancellationToken);
}
```

**Principle**: including two sibling collection navigations in one query makes EF Core join both into a single flat result set, so root rows get duplicated once per combination of related rows; a 10x10 Cartesian blow-up from two 10-item collections; `AsSplitQuery()` issues one SQL statement per collection, turning the product into a sum.

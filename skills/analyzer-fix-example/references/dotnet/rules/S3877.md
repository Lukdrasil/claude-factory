# S3877: Exceptions should not be thrown from unexpected methods

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: not configured; on by default (Sonar way) · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-3877/

## Wrong

```csharp
namespace Kit.Orders.Domain;

public sealed record Money(decimal Amount, string Currency)
{
    public override string ToString()
    {
        if (Amount < 0)
            throw new InvalidOperationException("Negative amount"); // Noncompliant: ToString must not throw

        return $"{Amount} {Currency}";
    }
}
```

## Right

```csharp
namespace Kit.Orders.Domain;

public sealed record Money(decimal Amount, string Currency)
{
    public override string ToString() =>
        Amount < 0 ? $"({-Amount}) {Currency}" : $"{Amount} {Currency}";
}
```

**Principle**: callers of `ToString`, loggers, debuggers, string interpolation, never expect it to throw, so it should render the exceptional value instead of raising; reject a genuinely invalid `Amount` where `Money` is constructed, not when it is printed.

# CA1869: Cache and reuse 'JsonSerializerOptions' instances

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: not configured; enabled by default as a suggestion (Info) in the .NET 10 SDK; an IDE-only hint, does not fail a warnings-as-errors build unless raised in `.editorconfig` · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1869

## Wrong

```csharp
using System.Text.Json;
using System.Text;

namespace Kit.Modules.Orders.Infrastructure.Webhooks;

internal sealed record OrderShippedPayload(Guid OrderId, DateTimeOffset ShippedAtUtc);

internal sealed class OrderShippedWebhookPublisher(HttpClient httpClient)
{
    public Task PublishAsync(OrderShippedPayload payload, CancellationToken cancellationToken)
    {
        var options = new JsonSerializerOptions { PropertyNamingPolicy = JsonNamingPolicy.CamelCase }; // new instance every call
        var json = JsonSerializer.Serialize(payload, options);
        return httpClient.PostAsync("webhooks/order-shipped",
            new StringContent(json, Encoding.UTF8, "application/json"), cancellationToken);
    }
}
```

## Right

```csharp
using System.Text.Json;
using System.Text;

namespace Kit.Modules.Orders.Infrastructure.Webhooks;

internal sealed record OrderShippedPayload(Guid OrderId, DateTimeOffset ShippedAtUtc);

internal sealed class OrderShippedWebhookPublisher(HttpClient httpClient)
{
    private static readonly JsonSerializerOptions Options = new() { PropertyNamingPolicy = JsonNamingPolicy.CamelCase };

    public Task PublishAsync(OrderShippedPayload payload, CancellationToken cancellationToken)
    {
        var json = JsonSerializer.Serialize(payload, Options);
        return httpClient.PostAsync("webhooks/order-shipped",
            new StringContent(json, Encoding.UTF8, "application/json"), cancellationToken);
    }
}
```

**Principle**: System.Text.Json caches reflection and serialization metadata per `JsonSerializerOptions` instance, so a static, reused options object amortizes that cost instead of rebuilding it on every call.

# CA1848: Use the LoggerMessage delegates

**Analyzer**: Microsoft.CodeAnalysis.NetAnalyzers · **Kit config**: suggestion · **Docs**: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1848

## Wrong

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Modules.Orders.Infrastructure;

internal sealed class OrderPublisher(ILogger<OrderPublisher> logger)
{
    public void Publish(Guid orderId)
    {
        logger.LogInformation("Published order {OrderId}", orderId); // parses the template on every call
    }
}
```

## Right

```csharp
using Microsoft.Extensions.Logging;

namespace Kit.Modules.Orders.Infrastructure;

internal sealed partial class OrderPublisher(ILogger<OrderPublisher> logger)
{
    public void Publish(Guid orderId) => LogOrderPublished(logger, orderId);

    [LoggerMessage(Level = LogLevel.Information, Message = "Published order {OrderId}")]
    private static partial void LogOrderPublished(ILogger logger, Guid orderId);
}
```

**Principle**: The source-generated `LoggerMessage` delegate parses the message template once at startup and passes `orderId` as a strongly typed parameter, avoiding both the per-call template parsing and the boxing that the `ILogger` extension method incurs.

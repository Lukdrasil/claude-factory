# S138: Functions should not have too many lines of code

**Analyzer**: SonarAnalyzer.CSharp · **Kit config**: warning in Features · **Docs**: https://rules.sonarsource.com/csharp/RSPEC-138/

## Wrong

```csharp
namespace Kit.Orders.Features.CheckoutCart;

internal sealed class CheckoutCartHandler
{
    public CheckoutResult Handle(CheckoutCartCommand command) // method length
    {
        if (command.Items.Count == 0)
            throw new InvalidOperationException("Cart is empty.");

        decimal subtotal = 0m;
        foreach (var item in command.Items)
            subtotal += item.UnitPrice * item.Quantity;

        var discount = 0m;
        if (command.CouponCode is not null)
        {
            if (command.CouponCode == "SAVE10")
                discount = subtotal * 0.10m;
            else if (command.CouponCode == "SAVE20")
                discount = subtotal * 0.20m;
        }

        var tax = (subtotal - discount) * command.TaxRate;
        var shipping = subtotal > 100m ? 0m : 9.99m;
        var total = subtotal - discount + tax + shipping;

        // ... twenty more lines of logging, event publishing, persistence
        return new CheckoutResult(total);
    }
}
```

## Right

```csharp
namespace Kit.Orders.Features.CheckoutCart;

internal sealed class CheckoutCartHandler
{
    public CheckoutResult Handle(CheckoutCartCommand command)
    {
        if (command.Items.Count == 0)
            throw new InvalidOperationException("Cart is empty.");

        var subtotal = CalculateSubtotal(command.Items);
        var discount = CalculateDiscount(subtotal, command.CouponCode);
        var total = ApplyTaxAndShipping(subtotal - discount, command.TaxRate);

        return new CheckoutResult(total);
    }

    private static decimal CalculateSubtotal(IReadOnlyList<CartItem> items) =>
        items.Sum(item => item.UnitPrice * item.Quantity);

    private static decimal CalculateDiscount(decimal subtotal, string? couponCode) => couponCode switch
    {
        "SAVE10" => subtotal * 0.10m,
        "SAVE20" => subtotal * 0.20m,
        _ => 0m,
    };

    private static decimal ApplyTaxAndShipping(decimal netSubtotal, decimal taxRate)
    {
        var shipping = netSubtotal > 100m ? 0m : 9.99m;
        return netSubtotal + netSubtotal * taxRate + shipping;
    }
}
```

**Principle**: A handler that inlines pricing, discount, and tax logic in one block aggregates three separate concerns into one unit; extracting each into a named method lets the top-level `Handle` read as the use case's steps, not its arithmetic.

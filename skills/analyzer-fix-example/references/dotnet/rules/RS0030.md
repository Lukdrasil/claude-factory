# RS0030: Banned API used

**Analyzer**: Microsoft.CodeAnalysis.BannedApiAnalyzers + BannedSymbols.*.txt · **Kit config**: banned APIs listed per layer; message after the semicolon in each line is the fix instruction · **Docs**: build/BannedSymbols.Domain.txt

## Wrong

```csharp
using System;

namespace Acme.Domain.Orders;

public sealed class Order
{
    public DateTime PlacedAt { get; private set; }

    public void Place()
    {
        PlacedAt = DateTime.UtcNow; // marker: banned API in domain
    }
}
```

## Right

```csharp
using System;

namespace Acme.Domain.Orders;

public sealed class Order
{
    public DateTime PlacedAt { get; private set; }

    public void Place(DateTime placedAt)
    {
        PlacedAt = placedAt;
    }
}
```

**Principle**: domain code must be deterministically testable, so the timestamp arrives as a method parameter instead of being read live; the caller in the application layer/adapter resolves it via `TimeProvider` and passes it in. Every `BannedSymbols.*.txt` entry names its own replacement the same way; the message after the semicolon in the offending line is the fix.

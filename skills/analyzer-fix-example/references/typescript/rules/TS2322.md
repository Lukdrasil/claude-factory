# TS2322: Type is not assignable to the target type

**Tool**: tsc · **Kit config**: always on (core structural type checking, no flag) · **Docs**: no per-code doc page; the compiler message names the types

## Wrong

```typescript
interface Point {
  x: number;
  y: number;
}

export function makePoint(): Point {
  const point: Point = { x: 1, y: "2" };
  return point;
}
```

## Right

```typescript
interface Point {
  x: number;
  y: number;
}

export function makePoint(): Point {
  const point: Point = { x: 1, y: 2 };
  return point;
}
```

**Principle**: `y: "2"` satisfies nothing about `Point.y` being a `number`, so any later arithmetic on `point.y` (`point.y + 1`) would silently do string concatenation instead of addition.

# TS18048: Value is possibly `undefined`

**Tool**: tsc · **Kit config**: noUncheckedIndexedAccess: true (kit tsconfig) · **Docs**: no per-code doc page; the compiler message names the types

## Wrong

```typescript
export function firstChar(values: string[]): string {
  const first = values[0];
  return first.charAt(0);
}
```

## Right

```typescript
export function firstChar(values: string[]): string {
  const first = values[0];
  if (first === undefined) {
    return "";
  }
  return first.charAt(0);
}
```

**Principle**: with `noUncheckedIndexedAccess`, `values[0]` is typed `string | undefined` because the array can be empty, so calling `.charAt` on it without a check would throw on an empty array at runtime.

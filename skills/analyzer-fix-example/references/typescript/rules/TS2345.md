# TS2345: Argument type is not assignable to the parameter type

**Tool**: tsc · **Kit config**: always on (core structural type checking, no flag) · **Docs**: no per-code doc page; the compiler message names the types

## Wrong

```typescript
function double(value: number): number {
  return value * 2;
}

export function run(): number {
  return double("5");
}
```

## Right

```typescript
function double(value: number): number {
  return value * 2;
}

export function run(): number {
  return double(5);
}
```

**Principle**: passing `"5"` where `double` expects a `number` would produce `"55"` from `*` coercion or `NaN`, not the arithmetic the caller intended; the compiler catches the mismatch before the wrong value ever runs.

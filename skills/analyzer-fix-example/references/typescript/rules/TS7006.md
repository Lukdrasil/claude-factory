# TS7006: Parameter implicitly has an `any` type

**Tool**: tsc · **Kit config**: strict: true (noImplicitAny) · **Docs**: no per-code doc page; the compiler message names the types

## Wrong

```typescript
export function makeAdder() {
  return function (amount) {
    return amount + 1;
  };
}
```

## Right

```typescript
export function makeAdder() {
  return function (amount: number): number {
    return amount + 1;
  };
}
```

**Principle**: without a contextual type to infer from, `amount` silently becomes `any`, so a caller passing a string would compile clean and only fail at runtime on the `+` operation.

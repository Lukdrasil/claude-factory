# N802: invalid-function-name

**Tool**: Ruff (pep8-naming) · **Kit config**: in kit `extend-select` ("N" group) · **Docs**: https://docs.astral.sh/ruff/rules/invalid-function-name/

## Wrong

```python
def GetUser(user_id: int) -> str:
    return str(user_id)
```

## Right

```python
def get_user(user_id: int) -> str:
    return str(user_id)
```

**Principle**: PEP 8's snake_case for functions is a strong, near-universal convention in the Python ecosystem, so deviating from it forces every caller to context-switch style mid-codebase for no semantic benefit.

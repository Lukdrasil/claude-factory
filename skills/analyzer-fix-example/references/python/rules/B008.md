# B008: function-call-in-default-argument

**Tool**: Ruff (flake8-bugbear) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/function-call-in-default-argument/

## Wrong

```python
from datetime import datetime


def create_session(created_at: datetime = datetime.now()) -> datetime:
    return created_at
```

## Right

```python
from datetime import datetime


def create_session(created_at: datetime | None = None) -> datetime:
    return created_at if created_at is not None else datetime.now()
```

**Principle**: default values are evaluated once at function-definition time, so `datetime.now()` would freeze at import time instead of reflecting the actual call time; inject it per call instead.

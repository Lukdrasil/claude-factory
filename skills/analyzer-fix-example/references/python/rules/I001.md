# I001: unsorted-imports

**Tool**: Ruff (isort) · **Kit config**: on by default (Ruff default set); also covered redundantly by kit `extend-select` ("I" group) · **Docs**: https://docs.astral.sh/ruff/rules/unsorted-imports/

## Wrong

```python
import sys
import os
```

## Right

```python
import os
import sys
```

**Principle**: consistently ordered imports make diffs deterministic, a new import lands in a stable spot, so a reviewer can see at a glance whether a dependency was added or removed, rather than shuffled.

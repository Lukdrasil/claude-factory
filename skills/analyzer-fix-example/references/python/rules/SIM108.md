# SIM108: if-else-block-instead-of-if-exp

**Tool**: Ruff (flake8-simplify) · **Kit config**: in kit `extend-select` ("SIM" group) · **Docs**: https://docs.astral.sh/ruff/rules/if-else-block-instead-of-if-exp/

## Wrong

```python
def sign(n: int) -> str:
    if n >= 0:
        result = "positive"
    else:
        result = "negative"
    return result
```

## Right

```python
def sign(n: int) -> str:
    return "positive" if n >= 0 else "negative"
```

**Principle**: a conditional expression collapses a four-line assign-then-return pattern into the single value it always was, removing an intermediate variable that exists only to be returned.

# S311: suspicious-non-cryptographic-random-usage

**Tool**: Ruff (flake8-bandit) · **Kit config**: in kit `extend-select` ("S" group) · **Docs**: https://docs.astral.sh/ruff/rules/suspicious-non-cryptographic-random-usage/

## Wrong

```python
import random


def generate_token() -> str:
    return str(random.randint(100000, 999999))
```

## Right

```python
import secrets


def generate_token() -> str:
    return str(secrets.randbelow(900000) + 100000)
```

**Principle**: the `random` module uses a Mersenne Twister PRNG that is predictable from its outputs, so anything security-sensitive (tokens, passwords) must draw from `secrets`, which is cryptographically secure.

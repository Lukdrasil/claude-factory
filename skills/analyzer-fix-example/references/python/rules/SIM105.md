# SIM105: suppressible-exception

**Tool**: Ruff (flake8-simplify) · **Kit config**: in kit `extend-select` ("SIM" group) · **Docs**: https://docs.astral.sh/ruff/rules/suppressible-exception/

## Wrong

```python
import os


def remove_cache(path: str) -> None:
    try:
        os.remove(path)
    except FileNotFoundError:
        pass
```

## Right

```python
import contextlib
import os


def remove_cache(path: str) -> None:
    with contextlib.suppress(FileNotFoundError):
        os.remove(path)
```

**Principle**: `contextlib.suppress` states the intent, "this specific exception is expected and ignored", in one line, instead of a try/except/pass block that reads like an accidental omission.

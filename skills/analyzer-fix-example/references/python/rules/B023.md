# B023: function-uses-loop-variable

**Tool**: Ruff (flake8-bugbear) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/function-uses-loop-variable/

## Wrong

```python
def make_multipliers() -> list:
    funcs = []
    for i in range(3):
        funcs.append(lambda x: x * i)
    return funcs
```

## Right

```python
def make_multipliers() -> list:
    funcs = []
    for i in range(3):
        funcs.append(lambda x, i=i: x * i)
    return funcs
```

**Principle**: closures capture the loop variable by reference, not by value, so every closure sees the loop's final value unless it is bound as a default argument at definition time.

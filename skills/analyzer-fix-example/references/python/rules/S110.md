# S110: try-except-pass

**Tool**: Ruff (flake8-bandit) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/try-except-pass/

## Wrong

```python
def load(path: str) -> str:
    try:
        return open(path).read()
    except Exception:
        pass
    return ""
```

## Right

```python
import logging

logger = logging.getLogger(__name__)


def load(path: str) -> str:
    try:
        return open(path).read()
    except Exception:
        logger.exception("failed to load %s", path)
    return ""
```

**Principle**: silently swallowing an exception erases the evidence needed to diagnose failures later; logging it preserves that signal while the function still degrades gracefully.

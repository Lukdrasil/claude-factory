# PLW0603: global-statement

**Tool**: Ruff (Pylint) · **Kit config**: in kit `extend-select` ("PL" group) · **Docs**: https://docs.astral.sh/ruff/rules/global-statement/

## Wrong

```python
_counter = 0


def increment() -> int:
    global _counter
    _counter += 1
    return _counter
```

## Right

```python
class Counter:
    def __init__(self) -> None:
        self._value = 0

    def increment(self) -> int:
        self._value += 1
        return self._value
```

**Principle**: mutable module-level state shared through `global` implicitly couples every caller to a single hidden instance, blocking reuse, parallel test runs, and reasoning about who changed the value.

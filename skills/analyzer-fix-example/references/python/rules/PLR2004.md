# PLR2004: magic-value-comparison

**Tool**: Ruff (Pylint) · **Kit config**: in kit `extend-select` ("PL" group); off in `tests/**` (per-file-ignores) · **Docs**: https://docs.astral.sh/ruff/rules/magic-value-comparison/

## Wrong

```python
def is_adult(age: int) -> bool:
    return age >= 18
```

## Right

```python
ADULT_AGE = 18


def is_adult(age: int) -> bool:
    return age >= ADULT_AGE
```

**Principle**: naming the constant documents what the number means and gives every future reader, and every other comparison against the same threshold, one place to change it.

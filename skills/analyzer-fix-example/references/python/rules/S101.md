# S101: assert

**Tool**: Ruff (flake8-bandit) · **Kit config**: in kit `extend-select` ("S" group); off in `tests/**` (per-file-ignores) · **Docs**: https://docs.astral.sh/ruff/rules/assert/

## Wrong

```python
def get_user(user_id: int, users: dict[int, str]) -> str:
    assert user_id in users
    return users[user_id]
```

## Right

```python
def get_user(user_id: int, users: dict[int, str]) -> str:
    if user_id not in users:
        raise KeyError(user_id)
    return users[user_id]
```

**Principle**: `assert` statements are stripped when Python runs with `-O`, so using them for input validation silently removes the check in optimized production runs; an explicit exception always executes.

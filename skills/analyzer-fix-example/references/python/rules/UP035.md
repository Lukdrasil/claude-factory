# UP035: deprecated-import

**Tool**: Ruff (pyupgrade) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/deprecated-import/

## Wrong

```python
from typing import Dict


def counts() -> Dict[str, int]:
    return {}
```

## Right

```python
def counts() -> dict[str, int]:
    return {}
```

**Principle**: `typing.Dict`/`List`/... are deprecated aliases scheduled for eventual removal; importing from `typing` for something the interpreter now provides natively is an unnecessary dependency and import-time cost.

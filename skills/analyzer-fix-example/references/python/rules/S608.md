# S608: hardcoded-sql-expression

**Tool**: Ruff (flake8-bandit) · **Kit config**: in kit `extend-select` ("S" group) · **Docs**: https://docs.astral.sh/ruff/rules/hardcoded-sql-expression/

## Wrong

```python
def find_user(conn, username: str):
    query = "SELECT * FROM users WHERE username = '" + username + "'"
    return conn.execute(query)
```

## Right

```python
def find_user(conn, username: str):
    query = "SELECT * FROM users WHERE username = ?"
    return conn.execute(query, (username,))
```

**Principle**: building SQL by string concatenation lets untrusted input change the query's structure (SQL injection); parameterized queries send the value through a separate channel the driver never interprets as syntax.

# E711: none-comparison

**Tool**: Ruff (pycodestyle) · **Kit config**: in kit extend-select ("E" group; not in Ruff's default set) · **Docs**: https://docs.astral.sh/ruff/rules/none-comparison/

## Wrong

```python
def is_missing(value: int | None) -> bool:
    return value == None
```

## Right

```python
def is_missing(value: int | None) -> bool:
    return value is None
```

**Principle**: `None` is a singleton, so identity comparison (`is`) is both the faster check and the only one immune to a class overriding `__eq__` to falsely compare equal to `None`.

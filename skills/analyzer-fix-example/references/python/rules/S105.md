# S105: hardcoded-password-string

**Tool**: Ruff (flake8-bandit) · **Kit config**: in kit `extend-select` ("S" group) · **Docs**: https://docs.astral.sh/ruff/rules/hardcoded-password-string/

## Wrong

```python
DB_PASSWORD = "hunter2"
```

## Right

```python
import os

DB_PASSWORD = os.environ["DB_PASSWORD"]
```

**Principle**: secrets committed as string literals end up in source control history forever; reading them from the environment (or a secret manager) keeps the credential out of the codebase entirely.

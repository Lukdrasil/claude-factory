# PLW2901: redefined-loop-name

**Tool**: Ruff (Pylint) · **Kit config**: in kit `extend-select` ("PL" group) · **Docs**: https://docs.astral.sh/ruff/rules/redefined-loop-name/

## Wrong

```python
def normalize(items: list[str]) -> list[str]:
    result = []
    for item in items:
        item = item.strip().lower()
        result.append(item)
    return result
```

## Right

```python
def normalize(items: list[str]) -> list[str]:
    result = []
    for item in items:
        cleaned = item.strip().lower()
        result.append(cleaned)
    return result
```

**Principle**: reassigning the loop variable inside the loop body hides the original value from later code and makes it impossible to tell, from the loop header alone, what the variable will hold on each pass.

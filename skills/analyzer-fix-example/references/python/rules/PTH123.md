# PTH123: builtin-open

**Tool**: Ruff (flake8-use-pathlib) · **Kit config**: in kit `extend-select` ("PTH" group) · **Docs**: https://docs.astral.sh/ruff/rules/builtin-open/

## Wrong

```python
def read_text(path: str) -> str:
    with open(path) as f:
        return f.read()
```

## Right

```python
from pathlib import Path


def read_text(path: str) -> str:
    return Path(path).read_text()
```

**Principle**: `pathlib.Path` methods operate on an object that also handles path joining, globbing, and existence checks uniformly, so replacing the free function `open()` removes the need to juggle `os.path` and `io` separately for the same file.

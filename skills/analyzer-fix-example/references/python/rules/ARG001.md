# ARG001: unused-function-argument

**Tool**: Ruff (flake8-unused-arguments) · **Kit config**: in kit `extend-select` ("ARG" group) · **Docs**: https://docs.astral.sh/ruff/rules/unused-function-argument/

## Wrong

```python
def process(data: list[int], verbose: bool) -> list[int]:
    return [x * 2 for x in data]
```

## Right

```python
def process(data: list[int]) -> list[int]:
    return [x * 2 for x in data]
```

**Principle**: an unused parameter is either leftover from a refactor or a forgotten wiring; removing it keeps the signature an honest description of what the function actually depends on.

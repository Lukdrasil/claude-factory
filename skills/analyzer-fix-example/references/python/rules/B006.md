# B006: mutable-argument-default

**Tool**: Ruff (flake8-bugbear) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/mutable-argument-default/

## Wrong

```python
def add_item(item: str, items: list[str] = []) -> list[str]:
    items.append(item)
    return items
```

## Right

```python
def add_item(item: str, items: list[str] | None = None) -> list[str]:
    if items is None:
        items = []
    items.append(item)
    return items
```

**Principle**: default argument objects are created once at function-definition time and shared across every call, so mutating one leaks state between calls that should be independent.

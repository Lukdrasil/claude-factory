# C901: complex-structure

**Tool**: Ruff (mccabe) · **Kit config**: in kit `extend-select` ("C90" group); limit 10 via `[lint.mccabe] max-complexity` · **Docs**: https://docs.astral.sh/ruff/rules/complex-structure/

## Wrong

```python
def shipping_cost(weight: float, country: str, express: bool, fragile: bool, insured: bool) -> float:
    cost = 0.0
    if weight <= 1:
        cost = 5.0
    elif weight <= 5:
        cost = 10.0
    elif weight <= 10:
        cost = 18.0
    elif weight <= 20:
        cost = 30.0
    else:
        cost = 50.0

    if country == "US":
        cost += 0
    elif country == "CA":
        cost += 5
    elif country == "MX":
        cost += 8
    else:
        cost += 15

    if express:
        cost *= 1.5
    if fragile:
        cost += 4
    if insured:
        cost += 6

    return cost
```

## Right

```python
def _weight_cost(weight: float) -> float:
    if weight <= 1:
        return 5.0
    if weight <= 5:
        return 10.0
    if weight <= 10:
        return 18.0
    if weight <= 20:
        return 30.0
    return 50.0


def _country_surcharge(country: str) -> float:
    return {"US": 0.0, "CA": 5.0, "MX": 8.0}.get(country, 15.0)


def shipping_cost(weight: float, country: str, express: bool, fragile: bool, insured: bool) -> float:
    cost = _weight_cost(weight) + _country_surcharge(country)
    if express:
        cost *= 1.5
    if fragile:
        cost += 4
    if insured:
        cost += 6
    return cost
```

**Principle**: splitting a function along its independent decision axes turns one hard-to-test tangle into several small functions each provable in isolation, and the caller's own complexity drops below the threshold.

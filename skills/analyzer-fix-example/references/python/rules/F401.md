# F401: unused-import

**Tool**: Ruff (Pyflakes) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/unused-import/

## Wrong

```python
import os


def greet() -> str:
    return "hello"
```

## Right

```python
def greet() -> str:
    return "hello"
```

**Principle**: an import that nothing in the module references is dead weight; it costs an import-time load and misleads readers about what the module actually depends on.

# B904: raise-without-from-inside-except

**Tool**: Ruff (flake8-bugbear) · **Kit config**: in kit extend-select ("B" group; not in Ruff's default set) · **Docs**: https://docs.astral.sh/ruff/rules/raise-without-from-inside-except/

## Wrong

```python
def parse(value: str) -> int:
    try:
        return int(value)
    except ValueError:
        raise RuntimeError("bad value")
```

## Right

```python
def parse(value: str) -> int:
    try:
        return int(value)
    except ValueError as err:
        raise RuntimeError("bad value") from err
```

**Principle**: `raise ... from err` preserves the original exception as `__cause__`, so the traceback shows the true root cause instead of looking like an unrelated, spontaneous failure.

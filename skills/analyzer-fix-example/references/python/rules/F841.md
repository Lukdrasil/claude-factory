# F841: unused-variable

**Tool**: Ruff (Pyflakes) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/unused-variable/

## Wrong

```python
def compute() -> int:
    result = 42
    return 7
```

## Right

```python
def compute() -> int:
    return 7
```

**Principle**: an assignment nothing reads back is either a forgotten return value or genuine dead code; either way it should not survive review unnoticed.

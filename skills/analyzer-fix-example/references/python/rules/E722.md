# E722: bare-except

**Tool**: Ruff (pycodestyle) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/bare-except/

## Wrong

```python
def read_config(path: str) -> str:
    try:
        return open(path).read()
    except:
        return ""
```

## Right

```python
def read_config(path: str) -> str:
    try:
        return open(path).read()
    except OSError:
        return ""
```

**Principle**: naming the exception type lets only the failure modes you actually anticipated be swallowed, so programming errors and `KeyboardInterrupt`/`SystemExit` still propagate instead of vanishing silently.

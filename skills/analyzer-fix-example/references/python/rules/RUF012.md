# RUF012: mutable-class-default

**Tool**: Ruff (Ruff-specific rules) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/mutable-class-default/

## Wrong

```python
class Config:
    items: list[str] = []
```

## Right

```python
from dataclasses import dataclass, field


@dataclass
class Config:
    items: list[str] = field(default_factory=list)
```

**Principle**: a bare mutable literal as a class attribute is one shared object referenced by every instance, so mutating it through one instance silently corrupts the state seen by all others; `field(default_factory=list)` gives each instance its own list.

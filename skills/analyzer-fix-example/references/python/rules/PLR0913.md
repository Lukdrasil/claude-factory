# PLR0913: too-many-arguments

**Tool**: Ruff (Pylint) · **Kit config**: in kit `extend-select` ("PL" group); limit 5 via `[lint.pylint] max-args` · **Docs**: https://docs.astral.sh/ruff/rules/too-many-arguments/

## Wrong

```python
def create_user(name: str, email: str, age: int, city: str, country: str, phone: str) -> None:
    pass
```

## Right

```python
from dataclasses import dataclass


@dataclass
class UserInfo:
    name: str
    email: str
    age: int
    city: str
    country: str
    phone: str


def create_user(info: UserInfo) -> None:
    pass
```

**Principle**: grouping related parameters into a single value object gives the collection a name and makes it type-checkable as a unit, instead of relying on positional/keyword argument order to convey structure.

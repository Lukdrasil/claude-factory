# UP006: non-pep585-annotation

**Tool**: Ruff (pyupgrade) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/non-pep585-annotation/

## Wrong

```python
from typing import List


def get_names() -> List[str]:
    return []
```

## Right

```python
def get_names() -> list[str]:
    return []
```

**Principle**: builtin generics (`list[str]`) have supported subscripting since Python 3.9, making the parallel `typing.List` alias pure boilerplate that adds an import with no functional benefit.

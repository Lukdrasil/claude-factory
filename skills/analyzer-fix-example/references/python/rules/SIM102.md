# SIM102: collapsible-if

**Tool**: Ruff (flake8-simplify) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/collapsible-if/

## Wrong

```python
def can_vote(age: int, registered: bool) -> bool:
    if age >= 18:
        if registered:
            return True
    return False
```

## Right

```python
def can_vote(age: int, registered: bool) -> bool:
    if age >= 18 and registered:
        return True
    return False
```

**Principle**: merging nested conditionals that share a single body into one `and` expression removes indentation that carries no additional branching information.

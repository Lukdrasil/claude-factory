# F821: undefined-name

**Tool**: Ruff (Pyflakes) · **Kit config**: on by default (Ruff default set) · **Docs**: https://docs.astral.sh/ruff/rules/undefined-name/

## Wrong

```python
def greet() -> str:
    return messsage
```

## Right

```python
def greet(message: str) -> str:
    return message
```

**Principle**: a name that was never bound raises `NameError` the moment this branch runs; catching it statically turns a guaranteed runtime crash into a build-time failure.
